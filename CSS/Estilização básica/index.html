Cores

Temos diversas formas de representar as cores dentro do css, dentre elas temos:

  • Cores pré-definidas
  • Hexadecimais
  • RGB e RGBA
  • HSL e HSLA

A letra "A" no RGBA e HSLA representam a opacidade

HSL e HSLA

hsl (hue, saturarion, lightness)

  • Hue (matiz): é o grau na roda de cores de (0 a 360).
    • 0 ou 360 é vermelho.
    • 120 é verde.
    • 240 é azul.
  • Saturarion (saturação): é o grau de saturação (0 a 100), em uma escala de porcentagem.
    • 0% totalmente cinza.
    • 100% cor total.
  • Lightness (luminosidade): representa a intensidade da cor.
    • 0% totalmente preta.
    • 100% cor total.
                
exemplos:

                
                    
pré-definidas

                    .exemplo{
                        color: blue;
                    }
                
                
                    
hexadecimais - Sem e com opacidade

                    .exemplo {
                        color: #0000ff; 
                        color: #0000ff80; 
                    }
                
                
                    
RGB e RGBA

                    .exemplo {
                        color: rgb(0, 0, 255); 
                        color: rgba(0, 0, 255, 0.5); 
                    }
                
                
                    
HSL e HSLA

                    .exemplo {
                        color: hsl(240, 100%, 50%); 
                        color: hsla(240, 100%, 50%, 0.5); 
                    }
Imagens e vídeos

Propiedade object-fit

A propiedade object-fit serve para controlar o comportamento da imagem.

Exemplo:

object-fit:fill; (padrão)
object-fit:contain;
object-fit:cover;
object-fit:none;
object-fit:scale-down;

Fill - preenche todo o espaco disponivel.

Contain - preenche todo o espaco disponivel, mantendo a proporcao.

Cover - preenche todo o espaço disponivel, ampliando a imagem.

None - matem a proporção da imagem.

Scale-down -a imagem será reduzida para a menor versão de none ou contain.


Propiedade object-position

A propiedade object-position serve para controlar a posicao da imagem.

Exemplo:

foram utilizados as propiedades object-fit:scale-down;
object-position:top;
object-position:bottom;

Top - posiciona a imagem no topo.

Bottom - posiciona a imagem no final.

Left - posiciona a imagem na esquerda.

Right - posiciona a imagem na direita.

Center - posiciona a imagem no centro.

Duas coordenadas- por exemplo: object-position: top left;

Porcentagem- pode-se utilizar uma porcentagem para definir a posição da imagem.
Exemplo: object-position: 50% 50%; (50% da largura e 50% da altura)

Alterando o fundo dos elementos

A propiedade background é a tag principal para alterar fundos.

Podemos utilizar a propiedade background-color para alterar a cor de fundo dos elementos.

Podemos utilizar a propiedade background-image para alterar o fundo dos elementos.

Podemos utilizar a propiedade background-size para alterar o tamanho do fundo.

Exemplos:

background-color: purple;
background-image: radial-gradient
background-image: linear-gradient;
background-image: url(link);
background-image: repeating-linear-gradient;

Redimensionando as Imagens de Fundo dos Elementos

Podemos utilizar a propiedade background-size para redimensionar as imagens de fundo dos elementos.

auto; - Define o tamanho da imagem de fundo automaticamente.

cover; - Aumenta o tamanho da imagem de fundo para cobrir o elemento.

contain - Mantem a proporção da imagem de fundo e reduz o tamanho da imagem de fundo para caber no elemento. Pode começar a se repetir dependendo do tamanho da imagem e elemento.

camada 1, camada 2; (contain, auto) - Sempre que utilizar camadas defina o png como a primeira camada.

Exemplo: background-image: url (link), url (link);


background-size: auto;
background-size: cover;
background-size: contain;
background-size: "valor"; (150px 150px)
background-size: "camada 1, camada 2";

Repetição das Imagens de Fundo

Para alterar a repetição das imagens de fundo, utiliza-se a propiedade background-repeat.

repeat; - Repetirá a imagem de fundo em todas as direções.

repeat-x; - Repete a imagem de fundo apenas na horizontal.

repeat-y; - Repete a imagem de fundo apenas na vertical.

space; - Repetirá a imagem de fundo em todas as direções, redimensionando a imagem. Gerando espaços entre as imagens para preencher o elemento.

round; - Repetirá a imagem de fundo em todas as direções, redimensionando a imagem para preencher totalmente o elemento.

no-repeat; - Não repete a imagem de fundo.

X e Y; - Podemos utilizar duas propiedades para alterar a repetição das imagens de fundo.

Exemplo: background-repeat: repeat space;


background-repeat: repeat;
background-repeat: repeat-x;
background-repeat: repeat-y;
background-repeat: space;
background-repeat: round;
background-repeat: no-repeat;
background-repeat: x y; (repeat space)
background-repeat: x y; (space repeat)

Posicionando Imagens de Fundo

Para posicionar as imagens de fundo, podemos utilizar as propriedades background-position.

background-position: top;
background-position: bottom;
background-position: left;
background-position: right;
background-position: center;
background-position: "x y" (bottom right);
background-position: "x y" (bottom 10px right 20px);
background-position: "porcentagem" (70% 70%);

Propiedade background-attachment

A propiedade background-attachment serve para controlar o comportamento da imagem de fundo.

scroll; - A imagem de fundo se move quando o usuário rola a página. Porém é fixa em relação ao conteudo.

fixed; - A imagem de fundo fica fixa ao fundo da página.

local; - A imagem de fundo fica fixa ao fundo do elemento. Rola junto com o conteudo.

initial; - A imagem de fundo é setada com os valores padrões.

inherit; - A imagem de fundo terá as propiedades herdada do elemento pai.

Propiedade Background Origin

Essa propriedade determina a partir de qual área a imagem de fundo é posicionada em relação ao elemento.

border-box: A imagem de fundo é posicionada em relação à borda do elemento, ou seja, a imagem começa a partir da borda externa do elemento, incluindo o padding e a borda.

padding-box: A imagem de fundo é posicionada em relação ao padding do elemento. Isso significa que a imagem começa a partir do início do padding, excluindo a borda.

content-box: A imagem de fundo é posicionada em relação ao conteúdo do elemento. Isso significa que a imagem começa a partir do início do conteúdo, excluindo o padding e a borda.

background-origin: border-box;
background-origin: padding-box;
background-origin: content-box;

Propiedade Background Clip

Essa propriedade é utilizada para definir até onde a imagem de fundo ou a cor de fundo de um elemento deve ser exibida. Essa propriedade controla a área em que o fundo é "recortado" ou "clipped", permitindo que você tenha um controle mais preciso sobre a aparência do fundo em relação ao conteúdo e à borda do elemento.

border-box: O fundo é exibido até a borda do elemento, incluindo o padding e a borda. Este é o valor padrão.

padding-box: O fundo é exibido apenas até a área de padding do elemento, excluindo a borda. Isso significa que o fundo não se estende para a área da borda.

content-box: O fundo é exibido apenas na área de conteúdo do elemento, excluindo tanto o padding quanto a borda. Isso é útil quando você deseja que o fundo não interfira no padding ou na borda.

text: Permite que o fundo de um elemento seja aplicado apenas ao texto. Para que o background-clip: text funcione corretamente, geralmente é necessario aplicar algumas outras propriedades CSS:

  • background-clip: text; Isso torna a cor do texto transparente, permitindo que o fundo apareça através das letras.
  • color: transparent; Isso torna a cor do texto transparente, permitindo que o fundo apareça através das letras
  • webkit-background-clip: text; O prefixo -webkit- é necessário para garantir a compatibilidade com navegadores baseados em WebKit, como o Chrome e o Safari.
background-clip: border-box;
background-clip: padding-box;
background-clip: content-box;
background-clip: text;

Mesclagem de Background

normal: Este é o valor padrão. As camadas de fundo não se misturam; cada uma é exibida separadamente.

multiply: As cores das camadas de fundo são multiplicadas, resultando em uma cor mais escura. Isso é útil para criar sombras e efeitos de profundidade.

screen: As cores das camadas de fundo são combinadas de forma a clarear a imagem. É o oposto de multiply.

overlay: Combina os efeitos de multiply e screen, dependendo da cor de fundo. Cores escuras são multiplicadas, enquanto cores claras são aplicadas com o efeito de screen.

darken: Reduz a cor das camadas de fundo, resultando em uma cor mais escura.

lighten: Aumenta a cor das camadas de fundo, resultando em uma cor mais clara.

color-dodge: Combina as cores das camadas de fundo com a cor de fundo, resultando em uma cor mais clara.

color-burn: A cor de fundo inferior é escurecida para refletir a cor superior.

hue: Mantém a luminosidade e a saturação da camada inferior, mas aplica a tonalidade da camada superior.

saturation: Mantém a luminosidade e a tonalidade da camada inferior, mas aplica a saturação da camada superior.

color: Mantém a luminosidade da camada inferior, mas aplica a tonalidade e a saturação da camada superior.

luminosity: Mantém a saturação e a tonalidade da camada inferior, mas aplica a luminosidade da camada superior.

  • border-width
  • border-style
  • border-color

também podemos modificar as bordas dos elementos de uma forma unica: border: width style color

Exemplo:

border: 15px solid black


Bordas com Imagens

A propiedade border-image permite que você use uma imagem para criar bordas em vez de usar as propriedades tradicionais de borda.

Temos as variações:

  • source: A imagem que será usada como borda. Pode ser uma URL de uma imagem ou um valor none para não usar imagem.
  • slice: Define como a imagem deve ser dividida. Pode ser um valor em pixels ou porcentagens, ou uma combinação de ambos. O valor padrão é 100%, que significa que a imagem será usada em sua totalidade.
  • repeat: Define como a imagem deve ser repetida. Os valores podem ser stretch, repeat, round, ou space.
  • width: Define a largura da borda. Pode ser um valor em pixels ou porcentagens. O valor padrão é medium.
  • outset: Define a quantidade de espaço que a borda deve ocupar fora do elemento. O valor padrão é 0.

Exemplos:

border-image-source:
border-image-source: linear-gradient
border-image-slice: 115
border-image-repeat: repeat
border-image-width: 10px
border-image-outset: 10px

Textos

Para modificar o texto utiliza-se a propiedade text-

Temos as seguintes propriedades:

  • text-transform - transforma o texto
    • text-transform: uppercase - transforma o texto em maiusculas.
    • text-transform: lowercase - transforma o texto em minusculas.
    • text-transform: capitalize - transforma o texto em maiusculas na primeira letra de cada palavra.
  • text-align - alinha o texto
    • text-align: left - alinha o texto para a esquerda.
    • text-align: right - alinha o texto para a direita.
    • text-align: center - alinha o texto para o centro.
    • text-align: justify - alinha o texto para o centro.
  • text-decoration
    • text-decoration: none - não define decoração no texto.
    • text-decoration: underline - define decoração no texto como sublinhado.
    • text-decoration: overline - define decoração no texto como sobrelinhado, linha acima do texto.
    • text-decoration: line-through - define decoração no texto como tachado.
  • text-indent - define a indentação do texto em relação ao primeiro parágrafo.
  • text-justify - define a justificação do texto.
  • letter-spacing - define o espaçamento entre as letras.
  • word-spacing - define o espaçamento entre as palavras.
  • white-space - define a forma como os espaçamentos entre as palavras se comportarão.
    • white-space: normal - define que o texto irá se comportar normalmente, não será possivel existir 2 espaçamentos entre as palavras.
    • white-space: nowrap - define que o texto não irá quebrar as linhas, permitindo que o texto seja exibido em uma linha.
    • white-space: pre - texto irá manter os espaçamentos entre as palavras, ignorando as quebras de linha e o tamaho do elemento.
    • white-space: pre-line - respeita a quebra de texto e o tamanho do elemento.
    • white-space: pre-wrap - o texto irá manter os espaçamentos entre as palavras, mas também irá quebrar as linhas.
    • white-space: break-spaces - ira quebrar os espaçamentos entre as palavras quando necessario, de acordo com o tamanho do elemento.
  • word-wrap - define como o texto irá quebrar as linhas, se manterá a palavra inteira ou irá quebrar as palavras.
    • word-wrap: normal - não ira quebrar a palavra.
    • word-wrap: break-word - ira quebrar a palavra ao meio, quando necessario.
  • word-break- define quando o texto deve quebrar as linhas.
    • word-break: normal - o texto irá quebrar as palavras quando necessario.
    • word-break: break-all - o texto irá quebrar as palavras em qualquer sílabas.
    • word-break: keep-all - o texto irá manter as palavras inteiras.
  • writing-mode - define a forma como o texto irá ser exibido (difine como o texto deve ser lido).

  • text-overflow funciona em conjunto com o white-space: nowrap, para que o texto não quebre em várias linhas.
    • text-overflow: clip - O texto que não couber no elemento será cortado e não será exibido. Este é o valor padrão.
    • text-overflow: ellipsis - O texto que não cabe será cortado e uma reticência (...) será adicionada no final para indicar que há mais texto.
    • text-overflow: string - Você pode especificar uma string personalizada que será exibida no lugar do texto cortado.

Overflow

A propiedade Overflow controla como o conteúdo que excede o tamanho de um elemento é tratado.

Ela possui 4 valores possíveis:

  • visible - O conteúdo excede o tamanho do elemento, ele fica visível. Este é o valor padrão.
  • hidden - O conteúdo excede o tamanho do elemento, ele fica oculto.
  • scroll - O conteúdo que excede o tamanho do elemento é cortado, mas barras de rolagem são adicionadas para permitir que o usuário veja o conteúdo oculto.
  • auto - O navegador decide se deve ou não adicionar barras de rolagem, dependendo do conteúdo. Se o conteúdo exceder o tamanho do elemento, as barras de rolagem aparecerão.
